# ESP32 BLE MIDI Controller

Проект MIDI-контроллера на ESP32-WROOM-32 с BLE MIDI, OLED-меню, шестью потенциометрами и восемью отдельными кнопками. В дальнейшем планируется поддержка матричной клавиатуры 4×4 и дополнительных функций.

> **Статус:** проект в разработке. Полный скетч компилировался в текущей конфигурации, но работу BLE MIDI, меню и всех событий необходимо проверить на реальном устройстве. Матрица 4×4 пока является планируемым расширением, а не подтверждённой частью прошивки.

## Возможности

- BLE MIDI с именем устройства `ESP33`.
- 6 аналоговых потенциометров с назначаемыми MIDI CC.
- 8 кнопок с индивидуальным назначением `NOTE` или `CC`.
- Для кнопок в режиме `NOTE`: Note On при нажатии и Note Off при отпускании.
- Для кнопок в режиме `CC`: настраиваемые значения при нажатии (`ON`) и отпускании (`OFF`) в диапазоне 0–127.
- Возможность назначить Sustain на любую кнопку: CC 64, OFF = 0, ON = 127.
- OLED SSD1306 128×64 по I²C.
- Сохранение назначений и MIDI-канала в NVS через `Preferences`.
- Сглаживание показаний потенциометров, ADC-гистерезис и порог отправки MIDI CC.
- Меню открывается удержанием UP в течение 2 секунд.

## Аппаратная часть

### Плата

- ESP32-WROOM-32
- Flash: 4 MB (согласно настройкам платы)
- Arduino-ESP32 core: 2.0.17

### Исходная распиновка

| Элемент | GPIO | Примечание |
|---|---:|---|
| Потенциометр 1 | 39 | ADC |
| Потенциометр 2 | 34 | ADC |
| Потенциометр 3 | 35 | ADC |
| Потенциометр 4 | 32 | ADC |
| Потенциометр 5 | 33 | ADC |
| Потенциометр 6 | 27 | ADC |
| UP | 13 | Вход в меню при удержании 2 секунды |
| DOWN | 19 | Навигация в меню |
| LEFT | 23 | Кнопка MIDI |
| RIGHT | 18 | Кнопка MIDI |
| Button 0 | 5 | Кнопка MIDI |
| Button 1 | 17 | Кнопка MIDI |
| Button 2 | 16 | Кнопка MIDI |
| Button 3 | 4 | Кнопка MIDI |
| OLED SDA | 21 | I²C |
| OLED SCL | 22 | I²C |

Кнопки в текущем скетче предполагаются активными по HIGH с подтяжкой вниз. Проверь соответствие электрической схемы этому предположению перед подключением питания.

### OLED

Ожидаемый дисплей: SSD1306, 128×64, I²C-адрес `0x3C`, SDA GPIO 21, SCL GPIO 22. Для дисплеев SH1106 потребуется другой драйвер.

## Управление

### Обычный режим

- Все 8 физических кнопок отправляют MIDI согласно назначенному режиму.
- Потенциометры передают назначенные MIDI CC.
- MIDI-канал общий для кнопок и потенциометров.

### Меню

- Удерживайте UP (GPIO 13) 2 секунды для входа в меню.
- UP и DOWN (GPIO 19) используются для навигации и изменения параметров.
- Остальные шесть кнопок временно не отправляют MIDI.
- Потенциометры продолжают передавать CC; изменение назначения CC должно применяться без выхода из меню.
- Длительное удержание UP используется для подтверждения/возврата в меню.
- Настройки сохраняются через `Preferences`.

### Режимы кнопок

**NOTE**
- Нажатие: Note On.
- Отпускание: Note Off.

**CC**
- Нажатие: заданное значение ON (0–127).
- Отпускание: заданное значение OFF (0–127).

Пример Sustain:
- Mode: `CC`
- CC: `64`
- OFF: `0`
- ON: `127`

## Программные зависимости

Установить в Arduino IDE:

- Arduino-ESP32 core 2.0.17
- BLE MIDI-библиотеку, которая предоставляет:
  - `BLEMIDI_Transport.h`
  - `hardware/BLEMIDI_ESP32.h`
  - макрос `BLEMIDI_CREATE_INSTANCE`
- MIDI Library (FortySevenEffects)
- Adafruit SSD1306
- Adafruit GFX Library

`Wire`, `Preferences` и ESP32 BLE входят в пакет Arduino-ESP32.

Названия и совместимость BLE MIDI-библиотек различаются. Если компилятор не находит `BLEMIDI_Transport.h`, необходимо проверить установку BLE MIDI-библиотеки и её совместимость с ESP32 core.

## Сборка

1. Установите зависимости.
2. Выберите плату **ESP32 Dev Module**.
3. Выберите подходящую схему разделов Flash в `Tools → Partition Scheme`.
4. Откройте основной `.ino`-скетч в Arduino IDE.
5. Скомпилируйте и загрузите прошивку.
6. Проверьте обнаружение BLE MIDI-устройства `ESP33` в совместимом MIDI-приложении.

Для текущего скетча ранее использовалась схема `Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)`. Если размер приложения приблизится к пределу, можно рассмотреть `Huge APP` при условии, что доступное место SPIFFS и необходимость OTA соответствуют требованиям проекта.

## Настройки фильтрации потенциометров

В текущем варианте используются:

- `FILTER_ALPHA = 0.20` — сглаживание IIR;
- `ADC_HYSTERESIS = 8.0` — гистерезис ADC;
- `MIDI_CC_THRESHOLD = 2` — минимальная разница MIDI CC для отправки.

Если отклик слишком медленный, можно увеличить `FILTER_ALPHA`. Если CC всё ещё дрожит, можно увеличить `MIDI_CC_THRESHOLD`. Изменения следует проверять на реальных потенциометрах.

## Примечания по матрице 4×4

Матрица 4×4 обычно использует 8 линий: 4 строки и 4 столбца. Для подключения напрямую нужны 8 подходящих GPIO. Перед выбором контактов следует учесть загрузочные GPIO ESP32 и занятые линии UART/I²C, а также возможное будущее подключение PCM5102A. Для экономии GPIO можно рассмотреть расширитель MCP23017 по I²C.

Матрица без диодов может давать ghosting при некоторых комбинациях нескольких одновременно нажатых клавиш. Это нужно проверить на конкретной клавиатуре.
